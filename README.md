# Selenium + Java — UI Tests

Небольшой учебный проект для практики автоматизации UI-тестов с использованием Selenium и Java.

## Что здесь есть

В проекте собраны простые e2e-тесты, которые покрывают базовые возможности Selenium:

- поиск элементов и локаторы
- проверки через `assert`
- работа с формами
- клики и ввод текста
- навигация между страницами
- работа с URL
- ожидания появления элементов
- базовая работа с Page Object Model

## Стек

- Java
- Selenium

## Цель проекта
Проект создан в учебных целях - чтобы на практике разобраться с Selenium, Java и основами UI-автоматизации.

Количество и сложность тестов намеренно небольшие.
По мере изучения Selenium проект будет дополняться более сложными сценариями.

## Запуск

Установить зависимости и собрать проект:

```bash
./gradlew build
```

Запустить все тесты:

```bash
./gradlew test
```

HTML-отчёт генерируется в:
```
build/reports/tests/test/index.html
```
